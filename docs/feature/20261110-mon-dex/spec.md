## 1. 背景与目标

`mon_data` 已经下发 `dex`（物种 id → 见过 / 收服次数），但 `CodexPanel` 只有动物图鉴和钓鱼图鉴，没有精灵页；`docs/FEATURES.md` 里也写着「还没有图鉴页」。

目标：

- 在统一的「图鉴」面板里加一页「精灵图鉴」。
- 让玩家看到自己见过 / 收服过哪些精灵、还差哪些，以及每种精灵的栖息地、进化链和收服记录。
- 纯客户端：只读 `mon_data.dex` 和共享内容数据，不改协议、不改服务端。

## 2. 用户与场景

- 玩家按 `H`（或菜单「图鉴」）打开图鉴，切到「精灵图鉴」。
- 看总体进度（已见 / 已收服 / 总数）。
- 按属性、是否收服、栖息地筛选。
- 点一只精灵看详情：名字、No.、属性、描述、进化链、栖息地、我的记录。
- 没见过的精灵只显示剪影和「？？？」，不泄露名字、描述和形象。

## 4. 正向场景

- **P1.** 打开图鉴 → 精灵图鉴，显示 `已见 X / 总数`、`已收服 Y / 总数`，列表按分组 + No. 升序；没有 `mon_data` 时显示「读取中…」，收到后自动刷新。
- **P2.** 三个分组标题正确；组内按 No. 升序；每组显示自己的已见 / 已收服进度。
- **P3.** 已见过的精灵显示名字、No.、属性；未收服显示 `见过 ×N`。
- **P4.** 已收服的精灵显示 `收服 ×N`，且 N 与 `dex[id].c` 一致。
- **P5.** 没见过的精灵显示剪影 +「？？？」；点击详情只显示剪影 + No. +「？？？」+「还没遇到」。
- **P6.** 选择某个属性后，只显示**见过**且含该属性的精灵；选「全部」恢复。
- **P7.** 勾选「只看已收服」后，只显示 `dex[id].c > 0` 的精灵。
- **P8.** 选择某个区域后，只显示该区域出没表里的**见过**精灵；「校园猫」「登录赠送」分别显示见过的猫系 / 耄耋。
- **P9.** 点击见过的精灵，详情显示 No.、属性、描述、进化链（含 Lv.16 / Lv.32）、栖息地、见过 / 收服次数。
- **P10.** 手机横屏下网格自动换列（4 列），详情不横向溢出。
- **P11.** 关闭图鉴再打开，筛选恢复「全部」；同一次打开里切去钓鱼图鉴再切回来，筛选保留。

## 5. 反向 / 异常场景

- **N1.** 没见过的精灵**绝不能**显示名字、描述、属性、栖息地、进化链、彩色形象；只能显示灰度剪影（图片 `brightness(0)`）/「？？？」。
- **N2.** 类型 / 区域 / 只看收服筛选**绝不能**把未见过精灵纳入结果（否则筛选结果会泄露属性 / 区域）。
- **N3.** 不认识的物种 id（旧客户端 / 新服务端）**绝不能**让页面崩溃；直接跳过。
- **N4.** `dex` 里没有条目时按「没见过」处理，不报错。
- **N5.** 客户端**绝不能**用 `learnset` / `zones` / 物种表本地推断「见过 / 收服」；只读 `mon_data.dex`。
- **N6.** 本页**绝不能**新增协议消息、要求服务端改字段或改存档。
- **N7.** 玩家可见文字**绝不能**用 `innerHTML` 渲染（沿用 `textContent`）。
- **N8.** 筛选结果为空时显示「没有符合条件的精灵」，不显示空白列表。
- **N9.** 多个筛选条件同时生效时取交集；清空条件恢复全部。
- **N10.** 猫系 / 耄耋没有野外区域时，栖息地显示「校园猫」/「登录赠送」，不出现 `undefined`。
- **N11.** 没有 `chain` / `evo` 的物种**绝不能**显示空的「进化链」标题。
- **N12.** 旧数据 / 空 `dex` 时显示空图鉴（0 / 总数），不崩溃；未见过卡片点开也不能泄露信息。

## 6. 数据 / 协议

- 只读 `mon_data.dex: Record<string, DexEntry>`（`{ s: 见过次数, c: 收服次数 }`）。
- 物种表来自 `CONTENT` / `SPECIES_LIST`（开放包 10 只 + 猫系 72 阶（24 毛色 × 3 阶段） + 耄耋）。
- 栖息地来自 `data/mons/zones.json` 的 `table[].sp`。
- **不改协议、不改服务端、不加存档字段。**

## 7. 界面与交互

- `CodexPanel` 增加 tab「精灵图鉴」；打开时请求一次 `mon_get`，收到 `mon_data` 后由 `MonPanel.onData` 触发刷新。
- 顶部：总进度（已见 / 已收服 / 总数）+ 进度条。
- 筛选条：属性（全部 + 18 属性）、「只看已收服」、区域（三个野外区域 +「校园猫」+「登录赠送」）；属性和区域用**像素风下拉**（不用浏览器原生 `<select>` 弹层）。
- 列表：三个分组标题 + 组内 `cx-grid`；卡片：
  - 未见过：物种图 `brightness(0)` 剪影 + No. +「？？？」；
  - 见过：`monArt` 图 + 名字 + No. + 属性徽章 + 见过 / 收服次数。
- 详情：No.、属性、描述、进化链（带 Lv.）、栖息地、我的记录；未见过只显示剪影 +「还没遇到」；无 `chain` / `evo` 不显示进化链。
- 手机横屏：4 列自适应，详情不横向溢出；不做搜索框。
