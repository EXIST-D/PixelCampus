# 战斗深度 2A-3：非伤害招式（IR #6 第三块）

> 对应 Issue：[EXIST-D/PixelCampus#6](https://github.com/EXIST-D/PixelCampus/issues/6)
> 规范：[docs/feature/spec.md](../spec.md)
> 状态：已确认（2026-11-12），待开工

## 0. 已确认的设计（本轮问答）

| 项 | 结论 |
|---|---|
| 命中 / 闪避 | **本批接入命中判定**：`acc × accuracyMul(命中−闪避)`，夹在 5%–100%；必中招式（`acc >= 100`）保持必中 |
| 招式类别 | 回复 / 变化 / 保护三类 + 降命中、升闪避 |
| 进入方式 | 加进现有物种的 `learnset`；不新增物种、不加学习器 / 商店 |
| 保护 | 本回合免伤；连续使用 ×0.5，最低 25%；换人或用其他招式中断 |
| 菜单 | 「威力 —」+ 效果说明；只显示基础命中，不折算 |
| 日志 | 回复写数值、变化用能力等级文案、保护写「守住了！/ 保护失败了……」 |
| 回复限制 | 只受 PP 限制（不限次数） |
| 睡觉 | 回满生命 + 自身 2 回合睡眠，PP 5；不清除毒/灼伤；睡/冻/麻痹时不能用 |
| 回复四类 | 睡觉、自我再生（1/2，PP 5）、吸取（伤害 50% 回血，PP 10）、小回复（1/4，PP 10） |
| 变化六种 | 剑舞（攻+2）、铁壁（防+2）、高速移动（速+2）、瞪眼（对方防−1）、影分身（闪避+1）、烟雾（对方命中−1） |
| 命名 | 同一机制多套名字（按属性 / 物种风味），**机制和数值统一** |
| 分给谁 | 开放包按属性各给风味招式；猫系一套「老吴」风味；野生精灵带少量 |
| AI | 本批**仍随机出招** |
| 满血回复 | 可以点，提示「生命已满」并照常消耗 PP |
| 不能行动 | 睡 / 冻 / 麻痹时全部招式禁用 |
| 守住成功 | 对方正常出招、扣 PP、播动画，伤害 0、附带状态被挡；日志「守住了！」 |
| 测试 | 单元 + 集成 + 确定性；全量全绿 |

## 1. 背景与目标

承接 2A-1（能力等级）和 2A-2（状态异常）。当前所有招式都是直接伤害；命中/闪避等级从 2A-1 起只显示不生效。

目标：

- 三类非伤害招式可用、有明确的数值和限制。
- 命中/闪避等级真正接入命中判定，不再只是显示。
- 招式名按属性 / 物种做出差异，机制复用、数值统一。
- 仍不改协议、不改存档。

## 2. 范围

### 本期做

- `Move` 扩展：`heal`（回复量 / 睡觉）、`guard`（保护）、`hitAcc` / `hitEva` 之类的效果描述（具体以实现为准，复用 `stat` 处理能力变化）
- 命中判定接入 `accuracyMul(命中 − 闪避)`
- 保护链衰减
- 回复四类、变化六种
- 开放包 / 猫系 / 野生精灵的 `learnset` 加招式
- UI：菜单「威力 —」+ 效果说明、满血提示、保护日志
- `BEvent` 增加回复 / 保护 / 保护失败事件

### 本期不做

- 技能学习器 / 商店购买
- AI 策略（本批仍随机）
- 天气 / 场地
- 命中/闪避以外的更多机制
- 协议 / 存档改动

## 3. 正向场景

- **P1.** 命中等级 +1 时，招式命中率按 `accuracyMul(+1)` 提高；闪避等级同理降低对方命中率。
- **P2.** 命中率夹在 5%–100%；必中招式不受影响。
- **P3.** 睡觉：回满生命，自身进入 2 回合睡眠。
- **P4.** 自我再生：回复最大生命 1/2；小回复：回复 1/4；吸取：造成伤害的 50% 回复自身。
- **P5.** 满血使用回复招式：提示「生命已满」并消耗 PP。
- **P6.** 剑舞 / 铁壁 / 高速移动 / 影分身：自身对应项 +2 / +1；瞪眼 / 烟雾：对方对应项 −1。
- **P7.** 守住：本回合免伤，对方照常扣 PP、播动画；日志「XX 守住了！」。
- **P8.** 连续守住：成功率 ×0.5、最低 25%；失败时日志「保护失败了……」。
- **P9.** 换人或用其他招式后，保护链中断，下次守住从 100% 开始。
- **P10.** 菜单显示「威力 —」+ 效果说明。
- **P11.** 睡 / 冻 / 麻痹时非伤害招式同样禁用。

## 4. 反向 / 异常场景

- **N1.** 命中率**绝不能**低于 5% 或高于 100%（必中招式除外）。
- **N2.** 守住**绝不能**挡住自己的状态异常（只挡对方这一回合的攻击及其附带效果）。
- **N3.** 连续守住**绝不能**低于 25%。
- **N4.** 回复招式**绝不能**把生命超过上限。
- **N5.** 睡觉**绝不能**清除中毒 / 灼伤。
- **N6.** 睡 / 冻 / 麻痹时**绝不能**使用睡觉或任何非伤害招式。
- **N7.** 本批**绝不能**新增协议消息或改 `protocol.ts`。
- **N8.** 招式**绝不能**写进存档（`Mon.mv` 只存 id + PP，沿用现状）。
- **N9.** 相同随机序列 + 相同行动**绝不能**结果不同。
- **N10.** 旧内容包 / 没有新字段的招式**绝不能**报错。
- **N11.** 玩家可见文字**绝不能**用 `innerHTML`；效果说明**绝不能**只靠颜色。
- **N12.** 命中/闪避等级的显示**绝不能**和实际结算不一致（UI 显示规则由共享函数提供）。

## 5. 数据 / 协议

- `Move` 增加可选字段（回复 / 保护 / 变化沿用现有 `stat`）。
- 内容包（`cat-mons.ts` / 开放包）增加招式名与 `learnset`。
- `BEvent` 增加 `heal` / `guard` / `guardfail`。
- **不改协议、不改存档、不加客户端消息。**

## 6. 界面与交互

- 出招菜单：非伤害招式显示「威力 —」+ 效果说明。
- 满血时点回复：提示「生命已满」，消耗 PP。
- 日志：回复数值、能力等级文案、守住成功 / 失败。
- 不能行动时全部禁用（沿用 2A-2 的 `.bt-blocked`）。
