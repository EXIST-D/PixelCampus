# 战斗深度 2A-2：状态异常（IR #6 第二块）

> 对应 Issue：[EXIST-D/PixelCampus#6](https://github.com/EXIST-D/PixelCampus/issues/6)
> 规范：[docs/feature/spec.md](../spec.md)
> 状态：已确认（2026-11-11），待开工

## 0. 已确认的设计（本轮问答）

| 项 | 结论 |
|---|---|
| 存储 | **只在本场战斗**（`Battle` 内，按精灵 id）；**不进 `Mon` 存档**、不改服务端存档、无迁移 |
| 中毒 | 每回合结束掉最大生命 1/8 |
| 灼伤 | 每回合结束掉 1/16；物理攻击威力减半 |
| 麻痹 | 速度减半；25% 概率当回合不能行动 |
| 睡眠 | 施加时随机 1–3 回合；回合结束计数 −1；到 0 下回合可行动 |
| 冰冻 | 每回合行动前 20% 解冻；未解冻不能行动 |
| 来源 | 只给现有招式加概率附带状态；**不新增纯状态招式** |
| 毒/灼伤击杀 | **可以打死野生精灵**，算正常胜利（给经验、记见过） |
| 换人 | 状态跟着精灵走，换下再上场保留 |
| 野生精灵 | 同样会中状态，AI 也会用带状态的招式 |
| UI | 状态标签与能力等级同一区域（文字 + 颜色）；日志写施加与每回合伤害 |
| 命中判定 | 本批**不接**；命中/闪避留到「非伤害招式」那批 |
| 不能行动 | 睡眠 / 冰冻时**完全不能行动**（不送出招 / 换人 / 扔球 / 逃跑） |
| 最坏情况 | 睡眠最多 3 回合；冰冻每回合 20%；UI 明确提示 |
| 叠加 | 同种状态**不叠加、不刷新**；睡眠与冰冻**互斥**；毒 / 灼伤 / 麻痹可共存 |
| 捕捉 | 睡眠 / 冰冻时捕捉成功率 **×2**；毒 / 灼伤 / 麻痹不加成；倍率放进 `catchChance()` 可选参数 |
| 不能行动 UI | 按钮禁用 + 顶部提示，客户端等待服务器推进，不需要玩家点 |

## 1. 背景与目标

承接 2A-1（能力等级）。当前战斗没有状态异常。

目标：

- 五种状态在战斗中真正生效、能看见、能解除。
- 毒 / 灼伤能参与削血和击杀；睡眠 / 冰冻影响行动与捕捉。
- 仍为战斗内状态：不进存档、不改协议、不加客户端消息。

## 2. 范围

### 本期做

- `Mon` 之外的战斗内状态：`Battle.status: Map<string, StatusState>`（按精灵 id）
- `Move.effect`（或 `Move.status`）字段：`{ s: StatusKind; chance: number }`
- 五种状态的效果、回合结算、解除
- `BEvent` 增加 `status`（施加）/ `statusdmg`（每回合伤害）/ `statusend`（解除）/ `blocked`（因状态无法行动）
- 战斗 UI 状态标签、日志、不能行动时的按钮禁用与提示
- `catchChance()` 增加睡眠/冰冻 ×2
- 给现有部分招式加状态概率

### 本期不做

- 纯状态招式（毒粉、催眠术等）
- 命中 / 闪避接入命中判定
- 状态进存档 / 跨战斗
- 天气 / 场地
- 能力等级之外的属性变化

## 3. 正向场景

- **P1.** 带状态概率的招式命中后，目标获得对应状态，事件 `status` 带状态与剩余回合（睡眠）。
- **P2.** 中毒：每回合结束目标掉最大生命 1/8，事件 `statusdmg`。
- **P3.** 灼伤：每回合结束掉 1/16，且物理技能伤害减半。
- **P4.** 麻痹：速度减半；25% 概率当回合不能行动（事件 `blocked`）。
- **P5.** 睡眠：1–3 回合不能行动，回合结束计数 −1，到 0 后解除（事件 `statusend`）。
- **P6.** 冰冻：每回合行动前 20% 解冻；未解冻则 `blocked`。
- **P7.** 毒 / 灼伤把野生精灵打到 0 血：正常胜利、给经验、记见过。
- **P8.** 状态跟着精灵走：换下再上场仍保留。
- **P9.** 同一种状态重复施加无效、不刷新；睡眠与冰冻互斥。
- **P10.** 睡眠 / 冰冻的野生精灵捕捉成功率 ×2。
- **P11.** UI 卡片显示状态标签（文字 + 颜色）；日志写「XX 中毒了！」「XX 因中毒受到了伤害」「XX 醒来了」。
- **P12.** 玩家被睡 / 冻住时，按钮禁用并提示「无法行动」，客户端等待服务器推进。

## 4. 反向 / 异常场景

- **N1.** 睡眠 / 冰冻**绝不能**同时存在。
- **N2.** 同种状态**绝不能**叠加或刷新回合数。
- **N3.** 状态**绝不能**写进 `Mon` 存档（`cleanMon` 前后一致）。
- **N4.** 本批**绝不能**新增协议消息或改 `protocol.ts`。
- **N5.** 命中 / 闪避**绝不能**在本批影响命中判定。
- **N6.** 毒 / 灼伤回合伤害**绝不能**为负，也**绝不能**让血量低于 0。
- **N7.** 已经倒下的精灵**绝不能**再触发状态伤害或状态事件。
- **N8.** 没有状态概率的招式**绝不能**产生 `status` 事件。
- **N9.** 状态解除后**绝不能**继续掉血或阻止行动。
- **N10.** 相同随机序列 + 相同行动**绝不能**结果不同。
- **N11.** 旧内容包 / 没有状态的战斗**绝不能**报错。
- **N12.** 玩家可见文字**绝不能**用 `innerHTML`；状态**绝不能**只靠颜色区分。
- **N13.** 捕捉倍率**绝不能**让成功率超出 5%–95% 的上下限。

## 5. 数据 / 协议

- `Move` 增加可选 `status?: { s: StatusKind; chance: number }`。
- `Battle` 增加 `status: Map<string, StatusState>`。
- `BEvent` 增加 `status` / `statusdmg` / `statusend` / `blocked`。
- `catchChance()` 增加可选参数（睡眠/冰冻时传 2）。
- **不改 `protocol.ts`、不改存档。**

## 6. 界面与交互

- 卡片下方 `.bt-stages` 旁显示状态标签（例如 `<span class="bt-status poison">中毒</span>`）。
- 日志：施加、每回合伤害、解除、无法行动。
- 不能行动：出招 / 换人 / 扔球 / 逃跑按钮全部禁用；顶部提示「你被冻住了，无法行动」。
- 客户端不主动推进回合，等服务器下一次 `mon_bt`。
