## 1. 背景与目标
- **问题 A（对战）**：玩家反馈「无法精灵双人对战」。排查：对战流程本身是通的，但邀请的所有结果（已发出、被拒、超时、离得太远、不在同一世界、一方在战斗中……）都走 `mon_result`，而它只在精灵面板 / 战斗界面 / 猫面板开着时才显示，邀请方点了「对战」后屏幕上什么都没有；另有几处状态检查缺失（接受时不再检查、野外遭遇不避让 PvP / BOSS、队伍问题的提示发错了人、邀请弹窗和野生遭遇弹窗叠在一起）。
- **问题 B（养猫）**：把猫接回宿舍后不小心「送回校园」，想再接回来必须先在校园里找到那只猫（它回到自己的固定家，不在宿舍旁；别人还可能正带着它），再打开面板点按钮，玩家找不到就接不回。
- **目标**：
  1. 邀请方、被邀请方在每一步都能在屏幕上看到明确的话（发出 / 等待 / 被拒 / 超时 / 为什么不能对战）。
  2. 接受邀请时重新检查双方状态，不会出现一边在野外战斗一边开 PvP；野外遭遇、猫战、训练家战不会在 PvP / BOSS 中途触发。
  3. 送回校园的猫，在「宿舍」面板里有「刚送回校园的猫」列表，一点就能接回（不用找猫、不用走近）；规则（好感、猫窝、容量、没在被别人带着）不放宽。
- **非目标**：不改对战引擎、不改奖励、不做「猫自动回宿舍门口」（另议）。

## 2. 需求
### 2.1 对战提示
- 邀请方：点「对战」后立刻看到「已向 X 发出对战邀请，等 TA 回应（30 秒）」的等待条；结果出来时（对方接受 → 战斗界面；被拒 / 超时 / 被服务器拒绝）显示原因，等待条收起。
- 被邀请方：邀请弹窗不与野生遭遇弹窗重叠；接受时若状态不允许，也看到原因。
- 服务器拒绝的原因都要是玩家看得懂的一句话（离得太远、不在同一个世界、正在战斗中、正在挑 BOSS、对方正被别人邀请……）。
- 一方没有能战斗的精灵：该方看到「你的出战队伍是空的…」，另一方看到「X 还没有能战斗的精灵」。
### 2.2 一键接回宿舍
- 送回校园成功后，服务器记住最近送回的猫（最多 3 只）；接回宿舍成功后从记录里去掉；宿舍存档持久化，下线后仍在。
- 「宿舍」面板新增「刚送回校园的猫」：每只猫一行「名字 + 接回宿舍」；现在不能接回时按钮置灰并写原因。
- 在宿舍里点「送回校园」成功的提示里说明「可以在『宿舍』面板里一键接回」。

## 3. 验收标准
- [ ] 本地两个浏览器：邀请方点对战立刻出等待条；对方接受进战斗；拒绝 / 超时 / 离得太远都有提示。
- [ ] 接受时对方正在野外战斗 → 被拒并说明；PvP 中走进草地不触发野外遭遇。
- [ ] 送回猫后「宿舍」面板出现它；点「接回宿舍」成功后消失；条件不满足时置灰并写原因；重连后记录还在。
- [ ] 新增测试覆盖以上规则；全量测试通过。
