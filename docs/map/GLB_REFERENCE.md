# 校园 GLB 模型：怎么用、能信多少

> 2026-11-04 调研与试用。文件 `参考资料/河北工程大学-校园模型-通用版.glb`（36 MB，**不入库**，已在 `.gitignore`；来源与许可未知，只当参考）。

## 它是什么
- gltfpack 输出的低模：无贴图、纯色材质（129 种）、约 96 万三角面、725 个节点；单位约为米，x 向东、z 向南、y 向上，范围约 1743 × 1300 m。
- 每栋楼一个顶层节点，名字带**官方楼号和中文名**（`01_library 图书馆`、`42_innovation 创新创业中心 / 工程实训中心`、`c1_A 第一社区 A 栋`、`44_international 留学生公寓`…）。还有湖、情人坡、湿地、球场、行道树、道路、围栏、海棠园/太极广场。
- 名字里有"局部推定""碑文留空"，是别人（或 AI）按卫星图重建的，**不是测绘数据**。

## 能信多少（对比卫星图的结论）
- **位置**：整体与我们的蓝图吻合，但**不是一个统一的变换**——全图拟合残差约 31 m；一、二社区局部拟合后缩放 ≈ 0.192 格/模型米（模型比真实大约 4%）、平移约 (178.1, 131.5)，楼脚印与我们量的重叠度 IoU ≈ 0.72；西门等处差到 5 格。所以**每块区域都要单独对位**，不能一个公式套全图。
- **楼形**：一、二社区的楼在模型里是"C / E / U 形整栋"（长板 + 连廊 + 短翼连在一起），按卫星屋顶叠上去后**比我们原来拆成 L 形的更贴**（二社区 E 栋的 45° 斜向 U 形尤其准）。但个别处模型是理想化的（连廊、小凸起），宿舍之外的楼（如图书馆）细节比我们简。
- **尺寸**：广场/景观类**会放大**——太极广场圆台模型直径约 62 m，卫星上只有约 44 m，不能直接用。
- **楼号/名称**：可用来核对。`42_innovation` = 创新创业中心，与用户说的 42 号楼一致；`44_international` = 留学生公寓。

## 工具（`tools/reference/glb/`，纯 Node，无依赖）
- `glblib.mjs`：读 GLB、遍历三角面、把一栋楼栅格化成脚印。环境变量 `GLB` 可换路径。
- `fit.mjs`：在"我们的蓝图楼 ↔ 模型楼"之间搜缩放+平移，使脚印重叠度最大。
- `decomp.mjs`：脚印 → 矩形翼体（`node tools/reference/glb/decomp.mjs c1_A [rot]`）。
- `retro.mjs`：楼群 → 连通分量 → 试旋转角 → 矩形（斜向的楼用）。
- 蓝图里用 `"ground": true`（坐标已是脚印，不再做视差修正）。

## 还没做 / 可以做
- 其余社区（三、四社区已被主人在编辑器里按真实名字合并过，没动）、学院楼群、体育场等可以同法对位后比较，但每处都要用卫星图当裁判。
- 模型里的行道树/灌木分布、情人坡、湿地的结构可作景观参考。
- 3D → 像素的底图渲染：只适合地标建筑试一两栋，模型是纯色，风格要另调。
