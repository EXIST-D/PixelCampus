# 地图管线与保真度

## 1. 为什么旧版比例不对
旧版把**透视鸟瞰图**当平面图用，线性拉成 8320×4576（1.82:1），南北被压扁近一倍。
真实校园（赵王大街↔毛遂大街 ≈ 1630 m，北环路↔太极路 ≈ 1210 m）约 **1.35:1**。新版不再使用鸟瞰图做几何，只用它做**命名和植被/风格参考**。

## 2. 数据来源（按可信度）
| 用途 | 来源 | 说明 |
|---|---|---|
| 建筑基底、广场、湖岸、运动场 | Esri World Imagery z18 正射图（0.479 m/px） | `npm run ref:fetch` 下载到 `.cache/`，**仅作几何参考，不入库、不分发** |
| 校园环路、门前车道 | OSM（source=Maxar 的无名道路） | `tools/reference/osm-roads.ts` 取数；蓝图里用 `"osm": <way id>` 引用，约 0.3 格精度 |
| 外围大街位置 | 卫星图量测 | OSM 带名字的大街（赵王/毛遂）与卫星图中心线差 3–5 格，**不采信** |
| 建筑名称、植被意图 | 你提供的鸟瞰图 | 北侧树山、银杏大道、粉樱主干、湖岸垂柳 |
| 内部次级道路 | 卫星图 + `snap_roads.py` | 手给大致折线，工具沿法线 ±2 格吸附到灰色路面脊线 |

**冲突时的取舍**：建筑/道路几何以卫星图为准；绿化与风格以鸟瞰设计图为准（卫星图北部仍是未绿化的荒地）。

## 3. 坐标系
- 世界 352×272 tile，1 tile = 5 m = 16 px。原点在卫星拼图像素 (400,1000)（`data/campus/geo.json`）。
- 蓝图里所有坐标都是 tile（浮点）。建筑翼体 `(x,y,w,d)` 为平面矩形，`y+d` 为南缘（深度排序基线）；`rot` 为绕中心顺时针角度。
- 编译时正向翼体边缘**吸附到整格**，使图像边缘与碰撞格严格重合（±0.5 格内的描图误差被吸收）。

## 4. 校验工作流（改地图必做）
```bash
npm run assets:world                      # 生成 .cache/coverage.png
npx tsx tools/reference/overlay.ts        # 蓝图叠加到卫星图：.cache/overlay/overview.png 与 ov_r*c*.png
python3 tools/analysis/road_gap.py        # 漏路检查：红色 = 卫星图里是路面、蓝图没覆盖  → .cache/road_gap.png
python3 tools/analysis/snap_roads.py      # 对带 "snap": true 的道路自动吸附
npm test                                  # 蓝图完整性 / 保真度 / 世界连通性
```
Python 依赖：`pip install numpy opencv-python-headless pillow`（仅分析用，游戏运行不需要）。

> **踩过的坑**：`road_gap` 揪出过"绿地文件排在道路之后，把弧路盖住"。图层顺序 = 文件名顺序：`00-base → 05-greens → 10-lake → 20/21-roads → 30-plazas → 40-sports`。

## 4.5 南门—图书馆中轴段（重点区，按卫星特写 + 旧版风格重做）
这一段是你对旧版最满意的部分，所以单独精修。关键量测（20px/tile 特写）：
- **轴线 x≈181**：图书馆入口台阶中心 181.25、南门门洞中心 ≈180、中央花园中线 180.4。注意：图书馆**屋顶**因楼高有视差，看起来偏东约 1.5 格，所以不能用屋顶轮廓定位，要用地面特征（台阶、广场）。
- **图书馆南广场**：x162.5–199、y180.5–211，是 3 行 × 东西对称的草坪格（行 y192.7–196.4 / 198–202.8 / 204.4–209.3），中央一块深色石面，南端是升旗台方石（x177.9–183.4）；北侧是 7.5 格宽的入口大台阶。
- **南门**：门线在 y≈240，两座小门卫亭夹 4 格门洞；门外前广场 y241–252 有校名石岛和两座小草岛；门内双车道（x≈174 / 187，中线虚线）夹中央花园（x176–184.7，南端圆角），外侧是浅色人行道。
- 综合服务中心（西）和会议服务中心（东）关于轴线对称（测试强制 ±2 格）。
**校名石**：石碑精灵 192×78 px（比最初放大 2 倍），"河北工程大学"用 24 px 像素字体写在碑面凹陷处（`60-landscape.json` 的 `label`，id=`schoolName`，碑面中心在脚点上方 40 px）。**彩蛋**：站在石碑正前方按 E（`interact` 区域）依次换成"河北宇达大学""河北美团大学"，第三次回到原名并提示"你发现了真正的河北工程大学"（顶部横幅 + 公屏一行）。特效：碑面闪白 → 文字向上跳 → 最高点换字、金色十字火花迸出 → 弹跳落回（`WorldScene.playEgg`，状态机在 `src/world/egg.ts`）。状态只在本机，不同步给其他玩家。

风格上借鉴旧版：红砖 + 深青玻璃带 + 石柱门廊的 `civic` 立面、银灰立缝屋面的会议中心、砖墙加铁栏的门墙、校名石 + 石球墩、金色多头路灯、旗杆（三帧旗）、校石（带裂纹的砂岩）。**未复用旧版 PNG**，全部按新色板和 16px/tile 重画。
查看特写：`npx tsx tools/reference/crop.ts 160 172 44 44 20`（卫星）、`npx tsx tools/reference/render-world.ts 1.5 140 160 80 100`（我们的渲染，同区域）。

## 4.6 西门 / 东门（按卫星特写重做，做法沿用中轴段）

- **东门**（门线 x≈331.5）：路口是**喇叭口**（x322–336.6, y164.4–174.2），中间有小圆岛，岛上立灰绿色**校训石**；门线上北立柱 + 红顶岗亭 + 南立柱，开口 4 格（实测 3.5）；外侧毛遂大街两条横向斑马线；两侧砖墙 + 铁栏；门牌"东门"、金色灯。杨树带为避开门墙移到 x333 / 335.3。

## 4.7 宿舍组团（一～四社区）与"斜视角视差"
**发现**：卫星图是斜视角，楼越高屋顶偏得越多，所以"量屋顶"得到的位置比真实脚印偏东北约 1~2 格；更麻烦的是**不同影像方向不同**——x<303 的影像能看到楼的西/南立面（屋顶偏东北），x≥303（四社区、东南角）看到的是东立面（屋顶偏西）。证据是楼侧面的深色/红棕色立面带。
**做法**：蓝图里仍填"量到的屋顶坐标"（便于对照卫星图），编译时按 `data/campus/geo.json` 的 `parallax`（每层偏移，分区）换算成脚印；已按地面特征量得的（图书馆、门卫室）设 `"ground": true` 跳过，单栋可用 `"par": [dx,dy]` 覆盖。游戏里的碰撞、门、道路关系都以脚印为准。不确定度约 ±0.7 格。
**校验**：`npx tsx tools/reference/compare.ts 28 60 36 66 16 c1` → `.cache/c1.png`，左=卫星（**品红框=按模型预测的屋顶位置**，应与卫星里的屋顶重合），右=我们的渲染（红=脚印，黄=门）。
**楼形**：宿舍几乎都是"长板 + 一条短翼"（短翼朝南或朝北、在东端或西端）的 L 形，已逐栋量出（一社区 8 栋、二社区 8 栋 + 两座 45° 斜楼 J/K、三社区 7 栋、四社区 5 栋板楼 + 两座小塔）。
**景观**：四周列植杨树带、楼间庭院草坪与灌木丛、三社区中心花园（环形园路 + 沙坑 + 海棠 + 长椅）、四社区东侧铺装带与灌木带、各楼门前自行车架；原"学生活动长廊"实为自行车停车场，已改正。
**体验**：6 层楼的立面（8.6 格高）比楼间距还大，屋顶会向北遮住庭院，所以加了"**玩家走到楼后面时整栋楼半透明**"（`WorldScene.updateBuildingFade`）。
**试过但放弃**：用颜色自动分割屋顶——屋顶和路面/硬地颜色太接近，分不开，只能手工量。

## 4.8 学院楼群（湖西 / 湖东 / 西南 / 东南）
**楼形**：不是矩形，而是长脊 + 若干板楼组成的 L / C / U / 回字形，已逐栋量出——
- 湖西：信息/机械/材料/矿业/地学院（长板 + 短翼）、实验实训楼（C 形开口朝东）、**第一公共教学楼**（"北长板 + 东长翼 + 南短翼"围合大院，另有一条 27° 斜翼和东侧平台）。
- 湖东：水利馆（U 形）、能源学院（C 形）、水院、数理、医学院、生科院、园林学院、试验楼，**第二公共教学楼**（C 形，朝东开口）。
- 西南：文法学院（U 形）、体育馆（四坡屋顶白色大馆）、管理/体育学院（圆塔 + V 形弧臂，用两条斜翼近似）。
- 东南：科研院（C 形）、**创新创业指导中心（回字形，带内院）**、工程实训中心（屋顶全是光伏板）、教育技术中心、研究生部。
**配套**：各楼前铺装带、内院草坪、行道树、长椅、车棚、公告栏；医学院南、数理东、水利馆院内等停车场有车辆；学院区内的楼间路与停车场见 `26-academic-paths.json`。
**校验**：`compare.ts` 的品红框（预测屋顶）与卫星屋顶重合度，我逐片看过：湖西、湖东两片很好；西南管理学院那个圆塔 + 弧臂只是近似；东南科研院的西翼被楼影遮住，位置是推的。

## 5. 已知偏差（诚实清单）
- 建筑基底为矩形/L 形近似，与卫星屋顶轮廓有 ±1 格偏差；**视差修正的不确定度约 ±0.7 格**，且只在宿舍区、图书馆、东南角做过验证，其余学院楼是"按同一模型换算"，尚未逐栋核对。
- 异形楼（圆形塔楼、曲线翼）用矩形/斜矩形近似。
- 水利水电学院试验厅与水利馆之间是封闭的停车庭院（卫星图如此），试验厅因此没有可进入的门。
- 西南管理工程与商学院：真实是"圆塔 + 弧形臂"，这里用两条斜矩形近似，拐点处有小缝；马克思主义学院那块（圆塔）也是矩形近似。
- 学院楼的视差修正仍是统一模型（见 §4.7），没有逐栋单独标定；若发现某栋偏移，在该楼条目里加 `"par": [dx, dy]` 单独覆盖。
- **建筑名称按位置对应鸟瞰图标注**，卫星图里有的楼比鸟瞰图标注多，多出来的用"配套用房/某社区X楼"等通用名。请你核对并告诉我改哪些。
- 次级小路（楼间人行道、花园园路）只收录了主要的；园林小径属于第二阶段（景观）。
- 西门门卫室实际更像两根立柱（约 1.5×2 格），这里做成 3×2 的小门卫室；东门红顶岗亭为近似。
- 中轴段：门卫亭/门墙/校名石的尺寸是游戏化（真实门卫亭约 2.5 格宽，这里做 3 格）；中央花园石面的"点阵铺装"以纯色石面近似；会议中心真实屋顶是浅米色+中央银灰大厅屋顶，这里整个做成银灰立缝屋面（旧版的做法）。
- 邯郸体育中心在校外，仅作地标（椭圆近似，不可进入）。
- 2026-11-09 起（主人在地图编辑器里改）：四社区新增 E / F / G / H 四栋宿舍楼（红砖 6 层，门朝南，位置按主人摆放，非卫星图量测）；建筑与艺术学院（含原建筑艺术博物馆）合并为一栋 6 层楼，五个翼体，南翼是正门，中间草坪上的连接楼与两侧同高；相邻翼体南边缘到下一翼北边缘要留够 ≥ 墙高（层数×22+6 像素）的间距，否则屋顶会盖住立面。
- 北部树山：按设计图画成林地；卫星图里目前仍是荒地。
