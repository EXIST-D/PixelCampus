## 一分钟上手

1. **有竿有饵**：每天第一次登录会送你鱼竿和鱼饵，做每日任务也送饵；不够了去商店或精工湖南岸的**钓具摊**买。
2. **走到精工湖边**，面朝水面（站得离岸边不远不近），按 **E** 抛竿。
3. 浮漂**沉下去、头顶冒「！」**就是咬钩了——2.2 秒内再按 **E** 提竿。
4. 进入**拉鱼小游戏**：按住**空格**（手机按住屏幕按钮）让右侧的**绿条**上浮，松开下沉，把鱼**留在绿条里**，进度满了就钓上来了；鱼离开绿条进度会掉，掉光鱼就跑了。
5. 钓上来的鱼出现在背包里，去**图书馆广场的校园商店**卖钱，或者留着喂小猫、放进宿舍浴缸、收集图鉴。

> 想知道**现在能钓什么、什么时候下雨、下一个夜晚什么时候来**：点右上角的时钟，打开「日历 · 天气」。

## 怎么钓

### 抛竿与咬钩
- 必须**面朝水面**、站在岸边（离水太远 / 太近都不行），在精工湖边的任意位置都可以钓。
- 抛竿后等 **2.5–8 秒**会咬钩（鱼竿、鱼饵越好等得越短）；超过 **45 秒**没动静会自动收线。
- 每抛一次竿**用掉 1 个鱼饵**（鱼饵没了抛不了竿）；太早收竿（还没咬钩）会有很短的冷却。
- 咬钩后要在 **2.2 秒**内提竿，晚了鱼就跑了。

### 拉鱼小游戏
- 右侧是一根水柱：**绿条**是安全区，**鱼标**是鱼；按住上浮、松开下沉。
- 鱼待在绿条里进度上升，不在里面进度下降；进度满 = 钓到，进度空 = 跑掉；**Esc 放弃**（鱼饵不退）。
- **越稀有的鱼越难拉**：鱼游得更快、绿条更短、更会窜动。鱼的游法有三种：**慢悠悠**、**时快时慢**、**突然窜动**——窜动的最难跟。
- 神话和传说鱼头顶会出现 👑；个别神话鱼**拉到一半会突然发力猛窜**，留一点余量。
- **拉得好（鱼几乎一直在绿条里）个头更大**，会出现「**完美**」；完美拉鱼的经验 +50%，还更容易刷新个头纪录。

### 个头与重量
每条鱼有长度和重量，分 **迷你 / 普通 / 较大 / 特大 / 巨物** 几档；大个头的鱼收购价也更高（同一种鱼，最大个头比最小的贵约三成）。

### 渔获卡
钓上来会弹出一张卡片：名字、稀有度、长度、重量，还可能有「**新种类**」「**新纪录**」「**巨物**」「**完美**」，以及这一条给了多少钓鱼经验。钓到保护动物时卡片上有「**放生**」按钮（见后文）。

## 环境：昼夜、天气、季节、节日

鱼出现的概率会随环境变化：有的**只在夜里**活跃，有的**下雨天**才容易遇到，有的只在**某个季节**多。

- **昼夜**：游戏里 1 天 = 20 分钟真实时间，白天长、夜里短。夜里（约 18:45 到次日 6:30）夜行鱼（黑鱼、鲶鱼、黄鳝、娃娃鱼……）更多。
- **天气**：天气每 8 分钟真实时间换一次；有晴、阴、雨（冬天是雪）。雨天（包括雷暴）泥鳅、虾虎鱼、黄鳝、娃娃鱼更活跃。**雾、彩虹、温度只是好看**，不影响钓鱼规则；雷暴按「雨」算。
- **季节**：每个季节 6 个游戏日（= 2 小时真实时间），一年 8 小时。春天龙门鲤、夏天河虾和小龙虾、秋天河蟹和黄河鲤、冬天银鱼和冰湖的鱼更多。
- **看预报**：点右上角时钟 →「天气预报」，能看到下一场雨/雪还有多久、下一个夜晚什么时候到，以及往后约 1 小时的预报（近 3 个时段精准，更远的只给有没有降水）。想钓**雨夜**的鱼，就等预报里「雨」和「夜晚」重叠的时候。
- **节日**：每个季节有一个节日（见下表），持续 2 个游戏日（约 40 分钟）。节日期间上线会**自动获得一件限定头饰**（永久保留），并有一点点钓鱼福利，**同一时间只会有一个节日，福利不叠加**。

## 装备

## 赚钱

- **卖鱼**：图书馆广场西侧的**校园商店**（门口按 E）。价格 = 鱼的基础价 × 个头系数 × **今日行情**（每个种类每天 0.85–1.25 倍，商店里标「行情好 ↑ / 行情差 ↓」）× 渔夫路线加成。同一种鱼个头越大越贵。
- **一键卖出**只收杂物、常见和少见的鱼；稀有及以上要手动卖（免得手滑卖掉舍不得的）。卖东西也可以**拉条选数量**。
- **别卖掉的东西**：图鉴要钓到过一次才记录，所以第一次钓到的稀有鱼卖掉也没关系；但想**喂猫**（好感）、**凑册页**、**宿舍浴缸展示**、**合成指名饵**的鱼可以先留着。背包每种最多放 999 个。
- **浴缸**：宿舍里有一个浴缸，把钓上来的鱼放进去养着（最多 12 种、每种 99 条）。**放进去的鱼不在背包里，不能卖、不能交易**，随时可以取回；稀有度越高、数量越多，水面越闪（少见绿 / 稀有蓝 / 史诗紫 / 传说金 / 神话彩虹），来做客的好友也看得到。纯展示，不给加成。
- **喂猫**：把鱼喂给校园里的小猫涨好感，鱼越稀有涨得越多（见稀有度表）。
- **省饵**：杂物 ×5 能合成鱼饵，小鱼 ×3 也能合成；每天登录和每日任务都送饵。

## 神话鱼攻略

神话鱼要**同时满足全部条件**才会出现，条件在图鉴里逐条显示；条件都满足以后，每杆大约有一成左右的机会遇到它（见神话表，每种略有不同），所以**难的是凑齐条件，不是运气**。准备工作做足，再挑天气和时间：

**河工锦**（春天白天的锦鲤）
1. 先钓满 **20 条锦鲤**（图鉴里的条数）。
2. 带 **香饵或更好的饵** + **碳素竿及以上**；等**春天、白天**（节日「樱花节」在春天，运气 +5% 也有帮助）。

**镇湖玄龟**（冬夜的大龟，绿条更短）
1. 合成**神话饵**（龙鳞 + 珍珠 + 稀有鱼）。
2. 用**寒江竿 / 金龙竿 / 龙骨竿**，在**冬天的夜里**抛竿；带声呐浮标可以咬钩时知道是不是它。

**应龙**（雨夜的龙，中途发力）
1. 同样准备**神话饵**。
2. 用**听雨竿或龙骨竿**，等**雨夜**——看预报里「雨」「夜」重叠的时段；拉到一半它会猛地发力，提前把绿条留在底部。

**怎么凑龙鳞和珍珠**：开**沉船箱**（龙鳞）和钓**河蚌**开珍珠；寻宝路线、拾遗竿、磁铁饵、寻宝钩、夜里和雨天都让盲盒更常出现。**龙骨竿**（金龙竿 + 龙鳞 ×4 + 1500 币，12 级）是顶级竿，2 个配件槽，也是神话鱼的入场券之一。

## 进阶技巧

1. **先学拉鱼，再升装备**：拉鱼不稳时，换「缓冲浮标」「铅坠」比换竿更划算；绿条越长越好抓。
2. **看天气选时间**：用预报安排钓鱼，雨天、夜里、对应季节叠在一起，传说和史诗的出现次数明显多。
3. **指名饵凑册页**：用 3 条同种的鱼合成指名饵，在装备栏指定图鉴里已有的鱼，一杆只会咬它，刷册页很高效。
4. **万能饵**（盲盒得到）无视季节 / 天气 / 昼夜（传说和神话除外），适合想钓某种「不是当季」的鱼。
5. **并蒂竿 + 野饵**：两个都有双钓概率，一次钓两条；但经验按条算，每日软上限会很快到。
6. **每天的经验有软上限**，用完之后不妨做委托、放生、冲新种类（这些不受限），或者去出售鱼。
7. **别忘了每周委托**：周一刷新，四个奖励里还有盲盒；**老板头顶亮「！」就去领**。
8. **想要稳定的零花钱**：渔夫路线 + 关注「行情好 ↑」的鱼，把行情好的鱼留到当天卖。

## 常见问题

**抛不了竿？** 要面朝水面，站在离水不远不近的岸边；背包里要有鱼竿和鱼饵；骑车、坐着时不能钓鱼（牵着手抛竿会自动松手）。

**提竿太晚鱼跑了？** 咬钩后只有 2.2 秒（含网络延迟）；寒江竿在冬天会把这个窗口加长。

**为什么今天钓到的经验变少了？** 超过了每日软上限（前 600 点全额，之后只算 40%）；换天（北京时间 0 点）就重置。

**神话鱼一直不出现？** 条件要**全部**满足：饵、竿、季节、昼夜、天气，还有图鉴里的前置（比如锦鲤条数）。在图鉴里点开看逐条的 ✔ / ✘。

**放进浴缸的鱼还能卖吗？** 不能，要先取回来。**能交易吗？** 也不能，放进去它就不在你的背包里了。

**盲盒怎么得到、能买吗？** 不能买，只能钓鱼时额外钓到；夜里、雨天、特殊装备和路线会让它更常出现。

**鱼竿不见了？** 竿不消耗；检查装备栏是不是选了别的竿，背包里每种竿只有一根。

**手机怎么拉鱼？** 按住屏幕上的拉鱼按钮上浮、松开下沉；手机的横屏更好操作。
