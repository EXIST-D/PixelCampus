# 0008 部署只由主人手动执行；公开仓库只在主人明确说「推公开仓库」时推送

- 状态：已采纳；**2026-11-10 起部分被 [ADR 0013](0013-collaborator-prod-deploy.md) 取代**：主人把正式环境的部署权下放给受信任的协作者（受限账号 + 预备份 + 自动回滚 + 审计）。「Claude 只在主人明确说部署时才部署」不变
- 日期：2026-11-07

## 背景
线上有真实玩家；有 bug 时公开仓库落后一点反而安全；部署会让在线玩家重连。

## 决定
开发完成后本地提交 + 同步私有仓库；主人说「部署」才执行（先备份数据 → `npm run deploy` → 校验页面哈希 / 服务状态 / `/healthz` / 日志）；公开仓库推送也要主人明确说。

## 后果
本地领先的公开提交没有远程备份，部署前后要提醒主人。

## 备选方案
每次提交后自动推公开仓库（2026-11-05 的旧约定，已作废）。
