# 0005 美术全部程序化生成，不引入第三方素材（字体除外）

- 状态：已采纳
- 日期：2026-10-31

## 背景
版权清晰、风格统一、可重复生成、便于多人协作（生成物不入库）。

## 决定
建筑 / 树 / 人物 / 小猫 / 物品 / 家具都由 `tools/art` + `src/art` 确定性生成；仅用 Ark Pixel 12px 字体（OFL）；人物小猫走 Rig 管线。本机的第三方素材包（`data/mons/packs/local-*`）不入库、不部署（部署脚本会拦）。

## 后果
改美术要重新生成并检查；老猫毛色与编号冻结（会影响好感记录）。

## 备选方案
购买 / 使用现成像素素材包（许可与风格不一致，被否）。
