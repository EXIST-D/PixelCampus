# 0007 地点留言：图片客户端压缩 + HTTP 上传券；带图留言先审后发

- 状态：已采纳
- 日期：2026-11-09

## 背景
每个地点要有留言板并可传图；服务器带宽曾被压到 1Mbps，内存上限 350MB，图片内容没有机器审核。

## 决定
浏览器里压成 WebP / JPEG（大图 + 缩略图，去 EXIF），先在 WebSocket 里要一次性上传券，再 `POST /up/<券>`；`GET /img/<名>` 永久缓存、流式读取；服务器只按魔数和大小检查、不转码；带图留言默认先审后发（`PLACE_IMG_PRE_REVIEW`），文字直接发布；被 3 人举报自动折叠；图片总量有上限。

## 后果
审核要管理员处理；删除的图片移入 `deleted/` 留证；备份要带上 `place-img/`。

## 备选方案
经 WebSocket 分片传图（占用游戏通道，被否）；服务端转码（占 CPU / 内存，被否）；全部发布后审核（有不当图片短时可见，被否）。
