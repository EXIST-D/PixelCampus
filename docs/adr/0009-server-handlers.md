# 0009 服务端按功能拆成 handler + 消息分发表

- 状态：已采纳
- 日期：2026-11-10

## 背景
`server/game.ts` 涨到 3027 行，新增消息要同时改两处长 `case` 列表，多人协作易冲突。

## 决定
`game.ts` 只留连接、加入 / 退出、移动校验、视野快照、发送、tick 和分发表；各功能在 `server/handlers/*-handler.ts`，通过窄接口 `GameCtx` 访问核心，并在 `register(d)` 里登记「消息类型 → 处理函数」（限流 / 打断牵手是表里的标志位）；重复登记启动即报错。

## 后果
新增消息只改一处；GameServer 仍保留约 60 个转发方法，可逐步去掉；`progress.ts` 暂未拆。

## 备选方案
继续在一个类里堆（被否）；把每个 handler 做成独立服务进程（过度设计）。
