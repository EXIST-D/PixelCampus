# 0006 玩家档案：快照 + 增量日志 + 离线冻结；2 万份时再评估 SQLite

- 状态：已采纳
- 日期：2026-11-10

## 背景
档案已有 8550 份、14MB；每份在内存里约 8.4KB，服务内存逼近 350MB 上限；写盘已有增量日志与分片合并，瓶颈是内存。

## 决定
离线 10 分钟且已落盘的档案在内存里冻结成压缩 JSON，用到时解冻，对外接口不变（实测每份 5.0KB → 2.2KB，RSS 262MB → 172MB）；`/healthz` 暴露 heapMB / rssMB / profiles / frozen；档案达 1.8 万份时告警，**2 万份时评估换 SQLite**；按 key 分片暂缓。

## 后果
启动时仍要先解析整个快照；全表扫描（名人堂、管理员列表）会临时解析冻结档案。

## 备选方案
直接上 SQLite（改动大、当前不必要）；按 key 分 16 片（解决写盘不解决内存，暂缓）。
