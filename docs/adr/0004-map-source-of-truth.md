# 0004 地图以卫星图为准，编辑器手动层覆盖；校园 GLB 模型只作参考，不迁 Godot

- 状态：已采纳
- 日期：2026-11-02 ~ 11-04

## 背景
要还原真实校园；旧版把透视图线性拉伸导致比例错误；曾调研 GLB 模型和迁移 Godot。

## 决定
几何真值 = 卫星正射图 + OSM 环路；蓝图 JSON + 主人在地图编辑器里改出的 `manual.json`（最后处理）编译成地面块 / 图集 / 碰撞；GLB 只用来对位参考；继续用 Phaser + TypeScript，不迁引擎。

## 后果
改地图要重新 `npm run assets`；部署后手动层自动并入 `baked.json`；南门到图书馆中轴段是主人最满意的部分，别随意改。

## 备选方案
迁移 Godot（工程成本高、收益不明，被否）；直接使用 GLB 几何（来源与精度不确定，被否）。
