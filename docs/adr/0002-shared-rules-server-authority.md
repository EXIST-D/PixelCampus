# 0002 规则写在 src/shared，服务器裁决，客户端只展示和请求

- 状态：已采纳
- 日期：2026-10-31（随联机服务器确立）

## 背景
多人在线游戏里，客户端不可信：价格、掉落、判定、冷却、距离都可能被篡改。

## 决定
校验和规则写成 `src/shared/` 里的纯函数；客户端用它显示和预判，服务器用同一份函数裁决并落盘；服务器不信任客户端发来的任何数值。所有玩家输入在服务端清洗（`cleanText` + 敏感词），客户端渲染一律 `textContent`。

## 后果
改了 `src/shared/*`（协议、规则、价格）必须同时部署服务端；规则有单测，两边行为一致。

## 备选方案
规则只写在服务端（客户端无法预判、界面要靠请求，被否）。
