# 0001 公开仓库只放客户端与共享规则，服务端与部署保持私有

- 状态：已采纳（服务端的具体放法见 [ADR 0012](0012-server-private-repo.md)：独立的私有仓库）
- 日期：2026-11-05

## 背景
项目要公开给同学 / 协作者看和参与，但服务器地址、部署脚本、敏感词库、管理员相关逻辑和服务端规则细节不适合公开；公开仓库也希望保持稳定，减少别人反复试错。

## 决定
`PixelCampus`（公开）只含客户端、`src/shared/` 共享规则、地图 / 美术数据与工具、公开文档；`server/`、`deploy/`、词库、`docs/private/`、依赖服务端的测试留在主人本机，另有独立的私有备份仓库保存。协作者用 `?offline` 单机模式开发客户端；需要服务端配合的改动写在 PR / `docs/feature/` 里，由主人实现服务端。

## 后果
协作者看不到服务端，改字段 / 新协议要靠 spec + plan 沟通（见 [服务端协作指南](../process/SERVER_COLLABORATION.md)）；私有部分只靠私有仓库备份，要记得 sync。

## 备选方案
服务端也公开（暴露运维与规则细节，被否）；服务端放进公开仓库的私有子目录（同一个 git 无法做到）。
