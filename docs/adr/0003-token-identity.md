# 0003 身份 = 浏览器里的随机 token，不做账号密码

- 状态：已采纳
- 日期：2026-10-31

## 背景
项目是个人学习作品、受众是校内同学，不想承担账号体系（找回、密码泄露、验证码）的复杂度和风险。

## 决定
客户端生成随机 token，服务器只存它的哈希；首次见到时分配永远不变的校园号（uid），好友 / 私聊只认 uid；换设备靠「身份备份码」。管理员口令唯一、只存 scrypt 哈希；协管员由站长在游戏里任命。

## 后果
token 丢了（清缓存）就要用备份码；没有「忘记密码」流程；档案与浏览器绑定。

## 备选方案
手机号 / 学号登录（要实名、要第三方，被否）。
