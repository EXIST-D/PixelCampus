# 架构决策记录（ADR）

> 记录「为什么这样做」：影响多个模块、难以回头的决定。**新增这类决定时加一份**（编号递增，不改旧的——被推翻就新增一份并把旧的状态改成「已被 NNNN 取代」）。
> 流程：重大功能的 plan 里写「方案比较」，定下来的结论沉淀成 ADR。

## 模板（复制成 `NNNN-短名.md`）

```markdown
# NNNN 标题

- 状态：提议 / 已采纳 / 已被 NNNN 取代
- 日期：YYYY-MM-DD

## 背景
为什么要做这个决定（约束、数据）。

## 决定
我们决定怎么做。

## 后果
带来的好处、代价、以后要注意的事。

## 备选方案
考虑过但没选的，以及原因。
```
