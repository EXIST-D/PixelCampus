## 改了什么

把本服（基于 2026-11-05 的 `PixelHue` 私有快照）里新增、而公开仓库目前没有的玩法，整理成 `contrib/` 下的 8 个模块：源码快照、按模块拆开的补丁、以及每个模块「接入时还要动哪些共享文件」的说明。

**这是「移植素材」PR，不是可以直接合并的运行代码**，原因有三，先说清楚免得误合并：

1. 你在 2026-11-06 连着合了好几批大更新（宿舍装修 / 39 件家具商店 / 墙纸地板 / 房间扩建 / 人气榜、钓鱼 3.0、日历天气节日、牵手 2.0、背包 999 与批量操作、性能优化）。三向比对下来，有 **46 个共享文件是双方都改过的**，直接把本服版本覆盖上去会回退你的改动。
2. 公开仓库按约定只放「客户端与共享规则」，不含 `server/`。而本服这些玩法（彩票开奖、赌鱼结算、实验田、公告播种）都是**服务端算结果再下发**的，客户端单独合进去跑不起来。
3. 因此本 PR **不修改任何现有文件**，只新增 `contrib/` 下的文件，零冲突、不影响构建与 CI。你可以按模块挑感兴趣的，我再拆成能直接合并的小 PR。

## 部署注意（给仓库主人）

真要接入时，这几处需要你在私有服务端同步，客户端这边合入前请备份 `players.json`：

- **协议**：本服 `PROTOCOL_VERSION = 12`。新增消息 `lot_draw / lot_result / lot_book`、`fish_bet*`、`boat_*` / `tandem_*`、`dorm_furn_buy / dorm_furn / dorm_like`、`farm_go / farm_leave / farm_get / farm_act → farm_in / farm_out / farm_data / farm_result`。你的 11/6 版本协议号不同，需要重新编号。
- **存档字段**：`Saved.fm`（实验田）、`Saved.fb`（赌鱼战绩）、`Saved.lt`（彩票）、`dm.fo / dm.fr / dm.fgf`（家具仓库与摆放）、`dm.dl / dm.lk`（点赞）。都要显式加进载入白名单，否则重启即丢。
- **先扣后算**：赌鱼先扣鱼再结算，彩票先扣币再开奖，避免断线重复领奖；两者都有服务端冷却。
- **美术 / 地图**：合入后重新 `npm run assets`（新增 `atlas-crops` 图集、温室家具、`farm.json` 房间、四个社区的菜地招牌）。
- **不要**把本服的站名「像素校园 瞬版本」、本服公告文案、sharecode、去掉黑夜、备份导出、安卓壳一起带过去——那是本服定制，已排除。
